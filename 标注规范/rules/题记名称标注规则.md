1. 概述

1.1 目的

将造像题记的原始信息，标准化为“地点简称 + 出资者 + 造像记”的统一命名格式，确保名称唯一、一致、可追溯。

1.2 适用范围


| 维度 | 说明 |
|---|---|
| 适用表 | inscriptions |
| 适用字段 | name |
| 适用材料 | 石窟寺、摩崖、石刻等造像题记 |

1.3 核心原则

唯一性：名称不可重复。当 地点简称 + 龛号 + 出资者 完全相同时，按出现顺序添加 -1, -2, -3... 后缀。
模块化：严格遵循“地点简称 + 出资者 + 造像记”结构。
优先级明确：出资者按固定优先级取值。

2. 分类体系

2.1 编码总表


| 编码 | 统一中文名称 | 判定要点 | 关键词/正则线索 | 备注/示例 |
|---|---|---|---|---|
| N01 | 地点简称 | 从最小、最具辨识度的地名至石窟/摩崖/寺庙 | (市|区|县|乡|镇|村)?(.*?(石窟|摩崖|石刻|寺|库房)) | 尖山子石刻、南龛石窟 |
| N02 | 出资者（个人） | 出资者字段有具体姓名 | ^[\u4e00-\u9fa5]{2,4}$ | 何君友、周氏 |
| N04 | 出资者（多人简化） | 出资者为多人 | 、|等 | 只取第一人 |
| N05 | 出资者（身份） | 使用身份代替姓名 | 进士|僧|居士 | 进士 |
| N03 | 龛号 | 出资者为不详且无法推断 | 第\d+号龛 | 第19号龛 |
| N06 | 固定后缀 | 统一以造像记结尾 | 造像记$ | 弥勒说法图记 → 造像记 |

2.2 特殊后缀（如有）


| 后缀 | 含义 | 使用规则 |
|---|---|---|
| -1, -2, -3… | 区分重复名称 | 当 地点简称 + 龛号 + 出资者 三者完全相同时，按出现顺序自动追加 |

3. 判定规则

3.1 规则一：地点简称提取

触发条件：存在“地点”字段
判断逻辑：
从完整地点字符串中，从最小地名开始匹配
截取至第一个“石窟/摩崖/石刻/寺/库房”为止
若有必要区分同一地点内的不同位置，可保留龛号（仅用于判定重复，一般不进入名称主体）
输出：地点简称

示例


| 项目 | 内容 |
|---|---|
| 输入 | 重庆市大足区铁山镇建角村尖山子石刻 7 号龛 |
| 匹配 | 尖山子石刻 |
| 输出 | 尖山子石刻 |

3.2 规则二：出资者取值

触发条件：存在“出资者”字段或可从佛像名推断
判断逻辑：
若有具体姓名 → 直接使用
若为“不详” → 尝试从所造佛像名中提取单人姓氏
若为多人 → 只取第一人姓名（除非明确为群体共造）
特殊场景 → 使用身份（进士、僧等）
若仍无法确定 → 使用龛窟编号
输出：出资者标识

示例


| 项目 | 内容 |
|---|---|
| 输入 | 出资者：惠志、敬修、法进 |
| 匹配 | 多人 |
| 输出 | 惠志 |

4. 编码规则

4.1 字段映射


| 原始字段/信息来源 | 目标字段 | 转换规则 |
|---|---|---|
| 地点 | 地点简称 | 按规则3.1提取 |
| 出资者 | 出资者标识 | 按规则3.2提取 |
| 固定后缀 | 造像记 | 固定追加 |
| 龛号 | 重复判定依据 | 不进入名称主体，仅用于区分重复 |

4.2 外键对应（如有）


| 编码值 | → 参考表 | 参考表字段 |
|---|---|---|
| 无 | — | — |

5. 归一化规则

5.1 同义词/异名合并


| 原始表述 | 归一化值 | 说明 |
|---|---|---|
| 大足尖山子 / 尖山子石刻 | 尖山子石刻 | 统一地点名称 |
| 周氏 / 周□□ | 周氏 | 残缺姓名保留姓氏 |

5.2 格式标准化


| 字段 | 标准格式 | 示例 |
|---|---|---|
| name | {地点简称}{出资者}{造像记} | 南龛石窟严武造像记 |
| name（重复） | {地点简称}{出资者}{造像记}-{序号} | 佛耳岩第9号龛造像记-2 |

6. 异常与缺失值处理


| 场景 | 处理方式 | 目标值 | 备注要求 |
|---|---|---|---|
| 地点字段为空 | 标记为缺失 | (地点缺失) | 需人工补录 |
| 出资者为空且无法推断 | 使用龛号 | 第X号龛 | 示例：第19号龛 |
| 地点+龛号+出资者完全重复 | 追加 -1, -2, -3... | 原名称-序号 | 按数据录入或发现顺序递增 |
| 无龛号且出资者不详 | 标记为缺失 | (出资者不详) | 需人工介入 |

7. 示例标注

示例 1（标准生成）

原始数据：
地点：四川省巴中市巴州区城南南龛山南龛石窟神仙坡北段 087 龛
出资者：严武
所造佛像：释迦说法图

标注过程：
地点提取：南龛石窟
出资者：严武
组合：南龛石窟 + 严武 + 造像记

标注结果：


| 字段 | 值 | 说明 |
|---|---|---|
| name | 南龛石窟严武造像记 | 标准格式 |

示例 2（出资者不详，使用龛号）

原始数据：
地点：北山佛湾第 19 号龛
出资者：不详

标注过程：
地点提取：北山佛湾
出资者：无法推断 → 使用龛号“第19号龛”
组合：北山佛湾 + 第19号龛 + 造像记

标注结果：


| 字段 | 值 | 说明 |
|---|---|---|
| name | 北山佛湾第19号龛造像记 | 龛号作为出资者替代 |

示例 3（重复名称判定，出资者不详）

原始数据：


| 记录 | 地点简称 | 龛号 | 出资者 |
|---|---|---|---|
| 记录A | 佛耳岩 | 第9号龛 | 不详 |
| 记录B | 佛耳岩 | 第9号龛 | 不详 |

标注过程：
出资者：不详且无法推断 → 使用龛号“第9号龛”
记录A：首次出现 → 佛耳岩第9号龛造像记
记录B：地点简称 + 龛号 + 出资者（龛号）与记录A完全相同 → 佛耳岩第9号龛造像记-2

标注结果：


| 记录 | name |
|---|---|
| 记录A | 佛耳岩第9号龛造像记-1 |
| 记录B | 佛耳岩第9号龛造像记-2 |
