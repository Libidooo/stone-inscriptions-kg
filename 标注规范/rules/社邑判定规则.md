1. 概述
1.1 目的
本规则用于从6-13世纪川渝石窟摩崖题刻中，系统、准确地判定题记所记载的宗教活动是否属于社邑组织活动，从而实现社邑组织字段的自动化标注，并为后续社会网络分析提供数据基础。
1.2 适用范围

| 维度 | 说明 |
|---|---|
| 适用表 | inscriptions |
| 适用字段 |  |
| 适用材料 | 川渝地区佛教石窟铭文（992条）中的社邑信息 |


1.3 核心原则
(1) 关键词优先原则：出现核心关键词，无论造像人数多少，直接判定为社邑活动
(2) 附带条件原则：次级关键词须满足特定条件（时间、宗教、搭配等）才能判定
(3) 互斥原则：社邑活动与集体活动互斥，同一题记不可同时归入两类
1.4 与其他规则的关系
社邑判定独立于宗派判定、主体识别等其他规则，可并行执行。

2. 分类体系
2.1 编码总表

| 统一中文名称 | 判定要点 | 具体判定规则索引 |
|---|---|---|
| 社邑 | 符合规则一或规则二中的任意判定条件 | 见3.1、3.2 |
| 集体活动（非社邑） | 不符合规则一、规则二，但满足规则三中的任意条件 | 见3.3 |
| 其他/无法判定 | 不符合规则一、规则二，也不满足规则三中的任意条件 | 默认分类 |

2.2 分层类别
社邑
非社邑

3. 判定规则
3.1 规则一：核心关键词 → 直接判定为社邑
触发条件：题记文字中出现以下任一关键词
判断逻辑：直接判定为社邑活动，无视造像人数多少

具体核心关键词

| 社邑称谓 | 社邑； 名称+社/邑：明真社、白衣社、施衣社、石室邑等（专有社名） |
|---|---|
| 社邑职位 | 平正、判曹、社首、勾当社首、社官、社老、社长、社务、纥首、虬首、乣首 |
| 社邑成员称谓 | 社户、众社户、诸社户、一社、两社、社众、社人、众户、众户弟子、社女、社女男、社男 |
| 社邑数量表述 | 数量+社一社、两社（即“数字+社”搭配） |
| 邑类组织称呼 | 义邑、法邑、邑会、义会 |
| 邑类职位称呼 | 邑长、邑主、邑师、社师 |
| 其他关键词 | 众愿、眾愿 |


示例

| 项目 | 内容 |
|---|---|
| 输入 | “石室神仙窟明真社碑……社老、社长、录事、社女男等” |
| 匹配 | “明真社”“社老”“社长”“社女男”均为核心关键词 |
| 输出 | 社邑 |


3.2 规则二：附带条件的关键词 → 需满足额外条件
3.2.1 “邑”字相关关键词
(1)  时间条件：唐宋时期与非唐宋时期
宗教条件：佛教与非佛教

| 关键词 | 条件与判断逻辑 | 判断结果 |
|---|---|---|
| “邑人”+人名/姓氏 / “邑人”后紧跟明显文字缺失 | 唐宋时期，邑人后跟具体人名或姓氏，或“邑人□”+修造行为 | 社邑 |
| “邑子”+人名/姓氏 / “邑子”后紧跟明显文字缺失 | 唐宋时期，邑子后跟具体人名或姓氏，或“邑子□”+修造行为 | 社邑 |
| “邑长/邑主/邑师”+人名/姓氏（或紧跟空缺） | 唐宋时期，“邑长/邑主/邑师”后跟具体人名或姓氏，或紧跟文字空缺后+修造行为 | 社邑 |
| 同邑 / 合邑 / 邑+缺失符号（邑□/邑(?)） | 唐宋时期，宗教为佛教，需结合核心关键词判断 | 无法判定 |
| 同邑 / 合邑 / 邑+缺失符号（邑□/邑(?)） | 唐宋时期，宗教非佛教（即道教等） | 社邑 |
| 名称+邑（如石室邑）/ 义邑 / 法邑 / 邑会 / 义会 | 唐宋时期，宗教非佛教 | 社邑 |


时间不为唐宋时期

| 关键词与判断逻辑 | 判断结果 |
|---|---|
| 出现上述任何“邑”字相关关键词 | 社邑 |

特别说明：邑人后必须跟具体人名或姓氏才能作为判定依据。如“邑人出力”中“邑人”作为独立概念，不作为判定依据。

示例

| 项目 | 内容 |
|---|---|
| 输入 | “邑人严从愿等以清识巽行乡……发弘愿建石龛” |
| 匹配 | “邑人严从愿”符合“邑人+人名”模式，时间属唐宋时期 |
| 输出 | 社邑（即使只有一人） |


3.2.2 部分职位类关键词

| 关键词 | 条件与判断逻辑 | 判断结果 |
|---|---|---|
| 勾当/都勾当/行首/头首 | 出现“勾当社首”“勾当+社邑职位”等与核心关键词搭配的形式 | 社邑 |
| 勾当/都勾当/行首/头首 | 题记文字中仅出现“勾当”而无核心关键词搭配（如“勾当镌造人”） | 非社邑 |
| 化首/化主 | 题记中其他位置出现核心关键词（如社户、社众等） | 社邑 |
| 化首/化主 | 题记文字中仅出现“化首/化主”而无核心关键词搭配 | 非社邑 |
| 上座/院主/观主/道首/解正道/维那/都维那/老宿/录事/门师 | 题记中其他位置出现核心关键词（如社首、社户、社众等）同时存在 | 社邑 |
| 上座/院主/观主/道首/解正道/维那/都维那/老宿/录事/门师 | 题记文字中仅出现“上座/院主/观主/道首/解正道/维那/都维那/老宿/录事/门师”而无核心关键词搭配 | 非社邑 |


判断逻辑总结：
这些职位类关键词单独出现时，不足以判定为社邑
必须与规则一中的核心关键词（如社首、社户、社众等）同时出现，才能判定为社邑
若多个此类关键词出现但无核心关键词，仍不判定为社邑

3.2.3 自我称呼类关键词

| 关键词 | 条件与判断逻辑 | 判断结果 |
|---|---|---|
| 弟子/女弟子/男弟子/信士/清信士 | 题记中其他位置出现核心关键词（如社首、社户、社众等）同时存在 | 社邑 |
| 弟子/女弟子/男弟子/信士/清信士 | “弟子/女弟子/男弟子/信士/清信士”+“社邑职位词”（如“弟子赵某，社首王某”） | 社邑 |
| 弟子/女弟子/男弟子/信士/清信士 | 仅出现“弟子/女弟子/男弟子/信士/清信士”无法判断 | 非社邑 |
| 弟子/女弟子/男弟子/信士/清信士 | “弟子”与“职位词”为同一人（如“弟子录事赵彭年”）且再无其他社邑职位 | 非社邑 |


示例

| 项目 | 内容 |
|---|---|
| 输入 | “弟子赵彭年……从事郎昌州录事军事参军” |
| 匹配 | “弟子”与“录事”为同一人，无其他社邑职位 |
| 输出 | 非社邑 |


3.3 规则三：集体活动（非社邑）排除性判定
触发条件：不符合规则一、规则二，但满足以下条件之一
判断逻辑：判定为集体活动，与社邑互斥


| 原则 | 具体条件 | 判断结果 |
|---|---|---|
| 数量原则 | ① 题记列出“人名/姓氏+几身”且≥3个不同姓氏；②“数字+户/家”且数字≥3；③ 直接列出≥3个不同姓氏人名 | 非社邑 |
| 多样性原则 | ① 参与者存在不同阶层（军、官、僧、民等）或不同职业、不同性别混合；② 存在募捐者/化众者（如“化众”“诱化”） | 非社邑 |
| 互斥原则 | 社邑活动属于集体活动的一种特殊形式，但在本规则中二者互斥。能判定为社邑的，不得归入集体活动；归入集体活动的，也不得再判定为社邑。 | 非社邑 |

示例标注
示例1：核心关键词直接判定
原始数据：“勾当社首岑忠用与裴氏夫妇共镌建”
标注过程：
“勾当社首”为核心关键词
触发规则一，无视人数
标注结果：
社邑

示例2：邑字附带条件判定
原始数据：“邑人严从愿等……发弘愿建石龛镌……大唐开元廿八年”
标注过程：
“邑人严从愿”符合“邑人+人名”模式
时间为开元廿八年（740年），属6-13世纪范围内
触发规则二之3.2.1
标注结果：
社邑

示例3：弟子+同一人职位→非社邑
原始数据：“弟子赵彭年……从事郎昌州录事军事参军赵彭年谨题”
标注过程：
出现“弟子”和“录事”两个关键词
但二者指代同一人（赵彭年）
无其他社邑职位词
不符合规则二之3.2.3中“弟子+职位且指代不同人”的条件
标注结果：
非社邑

示例4：集体活动排除判定
原始数据：“刘净意、陈静喜、李氏、文氏……化首、弟子”
标注过程：
无核心关键词
不符合规则二附带条件
姓氏≥3个不同姓氏（刘、陈、李、文）
触发规则三数量原则
标注结果：
非社邑
