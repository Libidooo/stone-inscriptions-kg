## 1. 概述

### 1.1 目的

以铭文文字为唯一判据，对题记造像者进行阶层分类与编码，实现从原始身份表述到标准化阶层字段的归一化映射。

### 1.2 适用范围

| 维度 | 说明 |
|------|------|
| 适用表 | inscriptions |
| 适用字段 | class_raw → class_type / class_unit / class_label / class_types_detail |
| 适用材料 | 四川地区佛教石窟铭文（992 条题记）中的造像者身份信息 |

### 1.3 核心原则

1. **唯一证据标准**：以铭文文字为唯一判据，不宜超出文本做主观推断
2. **先群体/个体再细化**：先判定造像者署名类型（A 群体 / B 个体），再按编码细化阶层
3. **保守判定**：信息不够时标 UNK 并在备注写明缺失原因（断代 / 残损 / 无署名等）

### 1.4 与其他规则的关系

阶层判定独立于宗派判定、主体识别等其他规则，可并行执行。阶层结果用于生成 class_type / class_unit / class_label / class_types_detail 四个字段。

## 2. 分类体系

### 2.1 群体类 A（Collective）

| 编码 | 统一中文名称 | 判定要点（文本条件） | 关键词/正则线索 | 备注 / 示例引用 |
|------|-------------|---------------------|----------------|----------------|
| A6 | 僧团僧伽 | 署名为寺院、僧众或僧团 | 寺、寺院、僧众、僧团、僧众共造 | 宗教机构集体供养；对应 B6 |
| A3 | 宗族官僚 | 群体署名含官职、家族/门第信息 | 刺史、参军、×氏、×家、门第、世祠、族人共造 | 士族合署（对应 B3、B4、B2） |
| A5 | 多阶混合 | 多阶层人物合署（如官员+弟子+众） | 同时出现官职词 + 弟子/众等 | 记录最高阶层到最低阶层（如 B3–B5b） |
| A7 | 平民合众 | 群体署名且无阶层线索 | 善男信女、众人、共造、合众、众、匠等 | 基层信众合资；对应 B7 |
| A0 | 未明群体 | 能辨为群体但无其它身份或人数线索 | 仅判读"众/共造"等，无人名或规模信息 | 与 UNK 区别：A0 能判为"群体"但无更细信息 |

### 2.2 个体类 B（Individual）

| 编码 | 统一中文名称 | 判定要点（文本条件） | 关键词/判断线索 | 备注 / 量化规则 |
|------|-------------|---------------------|----------------|----------------|
| B1 | 皇室宗亲 | 含"皇/帝/后/太子/宗室"等 | 皇、帝、后、宗室、太子、诏 | 最高阶层 |
| B2 | 封爵贵族 | 明确封爵或爵位（兼官职并入） | 公、侯、上柱国、勋爵 | 兼官职者仍归 B2 |
| B3 | 在职官员 | 文本有官职（刺史、参军等） | 刺史、参军、知州、县令、判官 | 无封爵则为 B3 |
| B4 | 名门士族 | 有"氏/家/门第/世祠"等 | ×氏、×家、门第、祠、世族 | 文化资本主导 |
| B5a | 豪强地主 | 含庄/宅/田/雇/主家等 | 庄、宅、田、主家、庄主、雇工 | 经济资本明显 |
| B5b | 虔诚弟子 | 识字且有独立供养能力，含"发心/设斋"等 | 弟子、奉为、发心、设斋、表赞、认妆、妆銮 | 单独造像数 ≥ 1 或妆修 ≥ 2 |
| B5c | 商贾匠人 | 含"舍银/舍钱/买/镌/发心造/工匠发心"等经济自资词 | 舍钱、舍银、镌、买、工匠、发心造、敬造、妆銮 | 匠人独立供养并入此项并标 -Craft |
| B5d | 军人武士 | 含军职、武职、兵士身份等 | 押衙、将、兵、军、武、都指挥、节度 | 武职系统，介于经济资本与政治资本之间 |
| B6 | 僧尼个体 | 署名含僧号（比丘、和尚、比丘尼等） | 比丘、和尚、比丘尼、僧正 | 宗教身份 |
| B7 | 基层百姓 | 家庭合署或个人识别且造像规模小 | 无任何头衔且字数稀少 | 满足（个人造像 < 1）或（妆修/重妆/报修 < 2），且无官职/土地/舍银/文化线索 |
| B9 | 信息空白 | 仅能辨为人名，无任何职业/家族/经济/宗教/规模线索 | 仅姓名或残字 | 与 B7 不同：B9 表示"只能判断为个人但没有其它信息" |
| UNK | 无法判定 | 铭文残损到无法辨认群体/个体身份或信息极其缺失 | — | 不要盲目归入 B7/B9，记录残损原因 |

### 2.3 特殊后缀

| 后缀 | 含义 | 使用规则 |
|------|------|---------|
| -Craft | 工匠属性 | 匠师自资供养 → 归入 B5c 并标注 B5c-Craft；仅落款 → UNK-Craft |
| J | 家庭合署 | 判断为家庭合署且属于某一阶层 → 编码后加 J（如 B7J） |
| (x-y) | 多阶跨度 | A5 多阶混合时记录最高阶层 x 与最低阶层 y（如 B3–B5b） |

### 2.4 可视化层级（社会等级自上而下）

```
B1   皇室宗亲（最高）
B2   封爵贵族（含兼官爵）
B3   在职官员
B4   名门士族
B5a  豪强地主
B5b  虔诚弟子
B5c  商贾匠人（含 Craft-A 标注）
B5d  军人武士
B6   僧尼个体
B7   基层百姓
B9   个体可辨但信息空白
UNK  无法判定（铭文严重残损）
```

## 3. 判定规则

### 3.1 个体判定优先级

**串行匹配，命中即止**：

```
B1 → B2 → B3 → B4 → B5a → B5b → B5c → B5d → B6 → B7 → B9 → UNK
```

- 从 B1 开始逐级向下尝试匹配
- 匹配到任一编码的关键词条件即终止并输出该编码
- 若全部不命中且铭文可读 → B9
- 若铭文残损到不可读 → UNK

#### 示例：个体判定

| 原始文本 | 匹配路径 | 结果 |
|---------|---------|------|
| "检校司空守昌州刺史" | B1 ✗ → B2 ✓（上柱国/勋爵） | B2 |
| "弟子何君友" | B1–B5a ✗ → B5b ✓（弟子） | B5b |
| "比丘尼惠志" | B1–B6 ✗ → B6 ✓（比丘尼） | B6 |
| "右衙第三军散副将种审能" | B1–B5c ✗ → B5d ✓（押衙/将） | B5d |

### 3.2 群体判定分支

- **A6（僧团僧伽）**：署名为寺院、僧众或僧团
- **A3（宗族官僚）**：群体署名含官职、家族/门第信息
- **A5（多阶混合）**：多人合署且阶层混合，记录最高与最低阶层
- **A7（平民合众）**：群体署名但无阶层线索
- **A0（未明群体）**：仅辨为群体，无任何细化信息

### 3.3 混合群体合署规则

若判定造像者为群体且为多阶层混合（多人合署）：

1. 记录合署者中最高阶层 x
2. 记录合署者中最低阶层 y
3. 标注为 (x-y)（如 "B2–B5c"）
4. 若有"主造/次造"或"主款/从款"等进行备注

### 3.4 工匠（Craft）处理细则

| 场景 | 处理方式 | 编码 |
|------|---------|------|
| 匠师仅落款（如"伏元俊镌记"） | UNK-Craft 标注，不计入主阶层 | UNK-Craft |
| 匠师以自身名义"发心敬造/妆銮/舍钱" | 视为独立供养者，归入 B5c | B5c-Craft |
| 匠师既为制作人又为合署资助者 | 写入主阶层 B5c-Craft | B5c-Craft |
| 为多人造像且属同一群体 | 按群体编码后加注 | A5（-with craft） |
| 为混合群体 | 标注 A5 并记录最高到最低阶层 | A5 (x-y) |

### 3.5 判定流程图

```
Start
  ↓
铭文是否可读？
  ├── 否 → UNK（备注残损原因）
  ↓ 是
能否辨为群体？
  ├── 是 → 群体分支：
  │   ├── 寺院/僧众/僧团 → A6
  │   ├── 含官职/家族信息 → A3
  │   ├── 多阶层合署 → A5（记录 x-y）
  │   ├── 有群体措辞但无阶层线索 → A7
  │   └── 仅辨群体无其他信息 → A0
  ↓ 否（个体）
按优先级 B1 → B2 → ... → B9 串行匹配
  ├── 命中 → 输出编码
  └── 不命中且铭文可读 → B9
  ↓
检查是否合署？
  ├── 否 → 输出
  └── 是 → 检测各署名编码 → 填写最高阶层—最低阶层
```

## 4. 编码规则

### 4.1 字段映射

| 原始数据/信息来源 | 目标字段 | 转换规则 |
|------------------|---------|---------|
| 原文身份表述（如"检校司空守昌州刺史"） | class_raw | 直接保留原始文本 |
| 判定出的编码（如 B2、B5b） | class_type | 取判定编码字符串 |
| 组织单位判定 | class_unit | 个人 / 家庭 / 群体 / 社邑 / 未知 |
| 编码 + 后缀组合（如"B5b-Craft"） | class_label | class_type + 后缀 |
| A5 多阶混合详情 | class_types_detail | 分号分隔（如"B3;B5b"） |

### 4.2 class_unit 判定规则

| 条件 | 值 |
|------|----|
| 署名指向单一自然人个体，无家庭合署 | 个人 |
| 明确提及家庭关系（如"合家""夫妇""二娘子"） | 家庭 |
| 三人以上共造且非家庭关系 | 群体 |
| 社/邑/社邑等组织 | 社邑 |
| 无法判断 | 未知 |

### 4.3 外键对应

| 编码值 | → class_types 参考表 | class_unit 值 | → class_units 参考表 |
|--------|---------------------|--------------|---------------------|
| B1–B9 / A0–A7 / UNK | class_types.id | 个人/家庭/群体/社邑/未知 | class_units.id |
| 复合标签（如 B5b-Craft） | class_labels.id | — | — |

## 5. 归一化规则

### 5.1 同义词/异名合并

| 原始表述（示例） | 归一化编码 | 说明 |
|----------------|----------|------|
| 皇帝 / 帝 / 后 / 太子 / 宗室 | B1 | 皇室宗亲 |
| 公 / 侯 / 上柱国 / 勋爵 | B2 | 封爵贵族 |
| 刺史 / 参军 / 知州 / 县令 | B3 | 在职官员 |
| ×氏 / ×家 / 门第 / 世族 | B4 | 名门士族 |
| 庄 / 宅 / 田 / 主家 / 庄主 | B5a | 豪强地主 |
| 弟子 / 发心 / 设斋 / 妆銮 | B5b | 虔诚弟子 |
| 舍钱 / 舍银 / 镌 / 工匠 | B5c | 商贾匠人 |
| 押衙 / 将 / 都指挥 | B5d | 军人武士 |
| 比丘 / 和尚 / 比丘尼 | B6 | 僧尼个体 |
| 无头衔且字数稀少 | B7 | 基层百姓 |
| 仅姓名或残字 | B9 | 信息空白 |

### 5.2 格式标准化

| 字段 | 标准格式 | 示例 |
|------|---------|------|
| class_type | 大写字母 + 数字 | B2、B5b、A5 |
| class_unit | 中文 | 个人 / 家庭 / 群体 / 社邑 / 未知 |
| class_label | class_type + 可选后缀 | B5b-Craft、B7J、A5(B2–B5b) |
| class_types_detail | 分号分隔，按阶层从高到低 | B3;B5b |

## 6. 异常与缺失值处理

| 场景 | 处理方式 | 目标值 | 备注要求 |
|------|---------|--------|---------|
| 铭文残损到无法辨认群体/个体 | 直接标 UNK | UNK | 记录残损原因（断代/残损/无署名） |
| 仅能辨为个体但无其他信息 | B9 | B9 | 说明除姓名外无任何线索 |
| 仅能辨为群体但无其他信息 | A0 | A0 | 说明群体规模和信息缺失情况 |
| 匠师仅落款无自资证据 | 不计入主阶层 | UNK-Craft | 标注于阶层一栏 |
| 信息不足且原因不明 | 备注说明 | UNK | — |
| 文本矛盾无法判定 | 取可靠性更高的证据 | 酌情 | 备注冲突情况 |

## 7. 示例标注

### 示例 1：个体 — 封爵贵族

**原始数据**

题记序号：3 | 原文身份："检校司空守昌州刺史" | 出资者：王宗靖

**标注过程**

1. 判断为个体（单人署名）
2. 按优先级 B1 → B2 匹配："检校司空"为勋官，上柱国系统 → 命中 B2
3. 无家庭合署标识 → class_unit = 个人
4. 无经济自资词 → 不加 -Craft

**标注结果**

| 字段 | 值 | 说明 |
|------|----|------|
| class_raw | 检校司空守昌州刺史 | 保留原文 |
| class_type | B2 | 封爵贵族 |
| class_unit | 个人 | 单人署名 |
| class_label | B2 | — |

### 示例 2：个体 — 虔诚弟子

**原始数据**

题记序号：2 | 原文身份："弟子" | 出资者：何君友

**标注过程**

1. 判断为个体
2. B1–B5a 均不匹配 → B5b 命中（"弟子"）
3. 无家庭合署 → class_unit = 个人

**标注结果**

| 字段 | 值 |
|------|----|
| class_raw | 弟子 |
| class_type | B5b |
| class_unit | 个人 |
| class_label | B5b |

### 示例 3：个体 — 工匠独立供养

**原始数据**

题记序号：52 | 原文身份："匠人" | 出资者：伏元俊、伏世能 | 铭文含"伏元俊镌记" + 明确供养

**标注过程**

1. 判断为个体（主署伏元俊）
2. B1–B5b 均不匹配 → B5c 命中（"匠人" + 自资属性）
3. 匠人身份明确且为独立供养 → 标注 -Craft

**标注结果**

| 字段 | 值 |
|------|----|
| class_raw | 匠人 |
| class_type | B5c |
| class_unit | 个人 |
| class_label | B5c-Craft |

### 示例 4：个体 — 军人武士

**原始数据**

题记序号：19 | 原文身份："右衙第三军散副将" | 出资者：种审能、常俊荣

**标注过程**

1. 判断为个体（种审能为主署）
2. B1–B5c 均不匹配 → B5d 命中（"右衙第三军散副将"含军职）

**标注结果**

| 字段 | 值 |
|------|----|
| class_raw | 右衙第三军散副将 |
| class_type | B5d |
| class_unit | 个人 |
| class_label | B5d |

### 示例 5：群体 — 多阶混合

**原始数据**

题记序号：58 | 原文身份："昌州充宁十将、摹刻匠人、住岩僧" | 出资者：文志、李大郎、罗复明、志诚

**标注过程**

1. 判断为群体（多人署名）
2. 阶层混合（B3 十将 + B5c 匠人 + B6 僧侣）→ A5
3. 记录最高 B3、最低 B5c → (B3–B5c)
4. class_unit = 群体

**标注结果**

| 字段 | 值 |
|------|----|
| class_raw | 昌州充宁十将、摹刻匠人、住岩僧 |
| class_type | A5 |
| class_unit | 群体 |
| class_label | A5(B3–B5c) |
| class_types_detail | B3;B5c;B6 |
