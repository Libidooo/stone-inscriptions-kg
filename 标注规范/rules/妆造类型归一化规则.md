## 1. 概述

### 1.1 目的

将题记中杂散的妆造类型原始描述（19种变体）归一化为互斥的标准分类，用于 Neo4j 图分析中的属性枢纽节点构建和宏观统计。

### 1.2 适用范围

| 维度 | 说明 |
|------|------|
| 适用表 | inscriptions |
| 适用字段 | makeup_normalized（派生字段，原始字段保留不变） |
| 适用材料 | 川渝地区佛教石窟铭文（992条）中的妆造类型信息 |

### 1.3 核心原则

1. **语义互斥**：5 个分类之间不重叠，每条题记只能归入一类
2. **动作优先**：以造像动作类型（新建/彩绘/修复）为分类依据
3. **复合归并**：同时包含新建和其他动作的，统一归入"新造兼妆修"

## 3. 判定规则

### 3.1 规则一：归一化判定流程

- **触发条件**：读取原始 妆造类型 字段值
- **判断逻辑**：

```
IF 值 为 空/无/[不详] → 返回 "不详"
ELSE IF 含"新造" AND (含"重修" OR 含"重妆" OR 含"镌妆") → 返回 "新造兼妆修"
ELSE IF 含"新造" → 返回 "新造"
ELSE IF 含"重妆" → 返回 "重妆"
ELSE IF 含"重修" → 返回 "重修"
ELSE → 返回 "不详"
```

- **输出**：归一化值（M01-M99）

#### 示例

| 项目 | 内容 |
|------|------|
| 输入 | "新造" |
| 匹配 | 仅含"新造" |
| 输出 | M01 新造 |

| 项目 | 内容 |
|------|------|
| 输入 | "新造 + 重妆" |
| 匹配 | 含"新造"且含"重妆" |
| 输出 | M02 新造兼妆修 |

| 项目 | 内容 |
|------|------|
| 输入 | "镌妆" |
| 匹配 | 仅含"镌妆"（镌造+妆銮，含新建属性，v1.1 显式分支） |
| 输出 | M02 新造兼妆修 |

| 项目 | 内容 |
|------|------|
| 输入 | "无" |
| 匹配 | 无有效记录 |
| 输出 | M99 不详 |

### 3.2 规则二：妆造-实践行为一致性校验（v1.1 新增）

> 依据 2026-09 妆造分类核实建议（#3 王宗靖、#48 何仪兴两条核实记录）：妆造类型归一化后，
> 应系统性地排查实践行为编码与妆造类型（及原文）的矛盾，作为归一化流程的固定校验步骤。
> 已实现于 `scripts/01_extract_and_clean.py`，输出 `data/cleaned/makeup_practice_contradictions.txt`。

- **触发条件**：归一化得到 makeup_normalized 后逐条比对实践行为（二级编码）
- **判断逻辑**：

```
IF makeup_normalized == "新造"(纯) AND 实践行为二级含妆修动作词（妆銮彩绘/复新重修/金装宝饰/妆修）
   → 标记矛盾：妆造=纯新造 但实践行为含妆修动作
IF makeup_normalized == "重妆"(纯) AND 实践行为二级含新造动作词（发心造像/镌刻雕造/绘塑造像等）
                                  AND 不含妆修动作词
   → 标记矛盾：妆造=重妆 但实践行为仅含新造动作
```

- **输出**：矛盾清单（当前 5.21数据 为 30 条），供人工对照原文复核，不自动改数。
- **历史核实结论**：
  - #3 王宗靖造观音地藏像记：原文"敬造""镌造"为新造用语，旧版实践编码（庄严修饰→重装修饰→补装增饰→补装修妆）有误；**5.21实体 已修正为 造像制作→发心造像**，妆造类型"新造"无误。
  - #48 何仪兴造像记：原文"发心镌造妆銮"兼含雕刻与彩绘，妆造类型"镌妆"准确；归一化遗漏（曾误标"缺失"），**v1.1 起归 M02 新造兼妆修**。
