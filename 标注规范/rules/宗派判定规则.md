## 1. 概述

### 1.1 目的

系统化分析四川地区佛教石窟铭文（石刻题记、造像记、碑刻）内容，判定造像主体归属与宗派流派，输出标准化判定结果（含证据链、信任得分、跨卷冲突消解）。

### 1.2 适用范围

| 维度 | 说明 |
|------|------|
| 适用表 | inscriptions（题记表） |
| 适用字段 | sect（宗派）、subject（造像主体）、class_type（阶层） |
| 适用材料 | 四川地区佛教石窟石刻题记、造像记、碑刻（唐代至宋代为主） |

### 1.3 核心原则

1. **前置过滤绝对优先**：任何条目必须先通过前置过滤，未通过者不得进入宗派判定
2. **主体判定优先**：五大主体（药师/弥勒/地藏/观音/阿弥陀）一旦判定，不得跨卷判断宗派
3. **密教绝对优先**：出现 W ≥ 60 的密教词（种子字/手印/曼荼罗/大日如来/明王）→ 必入卷五，其他卷全部靠后
4. **异体字工具化**：异体字仅用于题记识别和OCR校读，不得影响宗派权重
5. **四川地域特色**：重视卷八区域体系的地域信息，正确识别四川地名异体字
6. **证据链透明**：每条判定词必须具备出处、权重W、卷号归属V、判定逻辑

### 2.3 特殊说明

- **卷十（弥勒）**：仅判定主体是否为弥勒，不承担宗派判定功能。半跏思惟像为卷十最强判定，出现时绝对优先卷十
- **卷五（密教）**：最强"排他卷"，密教强因（W≥60）具有绝对优先权
- **卷十一（三论宗）**：无专属造像主体，通过否定结构、破斥性语言判定
- **卷十二（唯识宗）**：基于八识、三性、四分等认知结构判定
- **卷十三（天台宗）**：基于核心典籍、固定教观公式、祖师传承判定
- **卷十四（成实宗）**：基于《成实论》论名、五聚结构、梁代注疏系统判定
- **卷一**：所有词条基础权重 ≤ 25（弱因/中性因），不得单独用于判定宗派

## 3. 判定规则

### 3.1 规则一：前置过滤规则

#### 3.1.1 强制丢弃规则（R1-R3）

**R1｜显性备注型丢弃**
- **触发条件**：题记或资料备注中出现"不抽取实体"、"仅登记"、"仅记录"、"仅计数"、"不作判定"、"不进入判定"、"存目"、"资料性记录"
- **判断逻辑**：匹配任一关键词 → 直接丢弃
- **输出**：状态=丢弃

**R2｜功能性记录文本（无分析价值）**
- **触发条件**：文本内容属于以下类型之一：
  - 妆饰/重妆/装彩/修补/维修/再镌（物理维护记录）
  - 单纯施主名单（"施主张三、李四"）
  - 家族关系说明（"为父母、兄弟、妻儿"）
  - 匠师署名（"匠师王五镌刻"）
  - 年号/日期/地名（"大周天授元年三月"）
  - 无任何宗教叙述的事务性说明
- **判断逻辑**：匹配任一文本类型 → 直接丢弃
- **输出**：状态=丢弃

**R3｜信息不可判定文本**
- **触发条件**：连续可识别文字过少 | 漶灭/缺损导致无法形成宗教语义 | 全文仅剩格式性用语（"永为供养""功德无量"）
- **判断逻辑**：信息不足无法形成宗教语义 → 直接丢弃
- **输出**：状态=丢弃

#### 3.1.2 正向条件（允许进入分析）

**必须同时满足**：
1. 不存在 R1 任一禁止关键词
2. 文本明确呈现宗教叙述（而非事务记录）
3. 该叙述需要通过分析才能理解其性质

#### 示例

| 项目 | 内容 |
|------|------|
| 输入 | "弟子某甲，为亡父造药师如来像一躯，愿亡父往生净土" |
| 检查 | R1× R2× R3× → 无匹配；正向条件✓ |
| 输出 | 状态: 进入分析, 说明: 明确呈现宗教叙述 |

| 项目 | 内容 |
|------|------|
| 输入 | "施主张三、李四，匠师王五" |
| 检查 | R2匹配（施主名单）|
| 输出 | 状态: 丢弃, 说明: 功能性记录文本（施主名单） |

### 3.2 规则二：主体判定规则

- **触发条件**：条目已通过前置过滤
- **判断逻辑**（按优先级顺序）：
  1. 检查造像主体名号（药师/弥勒/地藏/观音/阿弥陀）
  2. 主体判定顺序：卷四（药师）→ 卷十（弥勒）→ 卷九（地藏）→ 卷二（观音）→ 卷三（阿弥陀）
  3. 密教强因 W ≥ 60 → 直接进入卷五
  4. 半跏思惟像 → 直接判定卷十（弥勒）
- **输出**：主体名称 + 所属卷号

**主体判定唯一性规则**：
- 主体一旦判定 → 不得再跨卷判断宗派
- 示例："药师佛 + 阿弥陀咒文" → 主体 = 药师 → 判定仍在卷四

### 3.3 规则三：宗派判定规则——综合得分（S）计算

**权重分（W）与综合得分（S）的转换公式**：

```
S = ΣW主要证据i + Σ(0.5 × W次要证据i)
```

**权重分等级定义**：

| 等级 | 权重范围 | 证据强度 | 宗派决定力 |
|------|---------|---------|-----------|
| A层决定因 | 80-85 | 主体明确，决定性证据 | 决定性 |
| B层强因缘 | 60-79 | 强力证据，显著支持判定 | 强 |
| C层中因缘 | 40-59 | 中等证据，辅助性支持 | 中 |
| D层弱因缘 | 20-39 | 弱证据，仅作参考 | 弱 |

**Gate规则（阈值控制）**：
- W ≥ 60：强因，触发宗派决定，直接进入对应卷
- 45 ≤ W < 60：中强因，可作为重要证据，需组合判断
- 25 ≤ W < 45：中等因，作为佐证
- W < 25：弱因，仅作为语言背景
- 密教（卷五）：W ≥ 60 直接入卷五，绝对优先
- 卷一（中性语料层）：W ≤ 25，不触发Gate

**综合得分与判定结果对应表**：

| 综合得分（S） | 判定结果 | 说明 |
|--------------|---------|------|
| S ≥ 160 | 确认为该卷 | 判定结果明确，无需进一步检查 |
| 120 ≤ S < 160 | 高概率 | 判定结果可靠，需检查冲突卷 |
| 80 ≤ S < 120 | 弱概率 | 判定结果较弱，需主体补强 |
| S < 80 | 不可判定 | 判定结果不可靠，需人工复核 |

### 3.4 规则四：主要证据与次要证据判定规则

#### 主要证据（Primary Evidence）

- **定义**：决定题记宗派取向的直接证据，权重 1:1 原数计入
- **包含内容**：
  1. **铭文中的宗派判定词**：如"生西方""往生""十二大愿""佛顶尊胜陀罗尼""无量光佛"
  2. **经文原句/经文词干**：如"观世音菩萨普门品""药师琉璃光如来本愿功德经"
  3. **本尊名号**：如阿弥陀佛、药师佛、尊胜幢、大威德
  4. **古代原刻题名**：题名若来自古代原刻（非现代研究命名）
  5. **宗派决定因图像**：如千手千眼、药师净土三重结构

#### 次要证据（Secondary Evidence）

- **定义**：仅具有"辅助性"的证据，权重减半计入（0.5 × W）
- **包含内容**：
  1. **地点信息**：如"安岳、简州"为药师/密教高频区
  2. **特定时代宗派流行趋势**：如广政年间密教高频
  3. **匠人、施主身份**：不构成宗派因缘，仅提示语境
  4. **图像构图的一般因缘**：如"三世佛""一佛二菩萨"等通用图像
  5. **杜撰性较高的题名**：现代命名、含糊的标签

#### 证据等级调整规则

1. 主要证据 ≥ 2 个 → S ≥ 160，确认为该卷
2. 主要证据 = 1 个 + 次要证据 ≥ 3 个 → 120 ≤ S < 160，高概率
3. 主要证据 = 0 个 + 次要证据 ≥ 5 个 → S < 80，不可判定，需人工复核
4. 证据之间存在冲突 → 应用互斥矩阵消解

#### 交叉佐证判定逻辑

```
IF 卷五词出现（W ≥ 60）→ 绝对密教（卷五）
ELSE IF 主体词（弥勒/药师/地藏/观音/阿弥陀）→ 按主体卷为主
ELSE IF 净土文出现 + 无药师/弥勒/地藏 → 卷三
ELSE IF 空宗逻辑（非有非无）→ 卷十一
ELSE IF 八识（阿赖耶识）→ 卷十二
ELSE 经文通用（卷一）→ 不参与宗派判定
```

| 非有非无 / 八不中道 | 八不中道 | 卷十一三论宗核心 |

### 5.2 异体字归一化

异体字仅用于题记识别和OCR校读，**不得影响宗派权重**。

| 异体字 | 正体字 | 说明 |
|--------|-------|------|
| 仏 | 佛 | OCR常见变体 |
| 薩 | 萨 | 字形简化 |
| 無 | 无 | 字形差异 |
| 衆 | 众 | 字形差异 |
| 広 | 广 | 字形差异 |
| 蔵 | 藏 | 字形差异 |
| 経 | 经 | 字形差异 |
| 峗 | 危 | 四川地名异体（如"资峗"→"资危"） |
| 嶽 | 岳 | 四川地名异体（如"安嶽"→"安岳"） |

### 5.3 格式标准化

| 字段 | 标准格式 | 示例 |

## 6. 异常与缺失值处理

| 场景 | 处理方式 | 目标值 | 备注要求 |
|------|---------|--------|---------|
| 主体不明 | 不得判宗派 | 宗派 = "宗派未定" | 主体栏填"主体不明" |
| 无任何宗派判定词 | 不可判定 | S < 80，宗派 = "不可判定" | 需人工复核 |
| 跨卷冲突（⛔） | 应用互斥矩阵消解 | 保留优先级高的卷 | 须在备注说明冲突情况 |
| 密教强因 + 非密教主体 | 绝对进入卷五 | 宗派 = 密教 | 备注说明"密教强因优先" |
| 仅存格式性用语（"永为供养"） | 前置过滤R3丢弃 | 状态 = 丢弃 | 信息不足 |
| OCR识别率 < 30% | 按R3处理 | 状态 = 丢弃 | 无法形成有效宗教语义 |
| 同时满足多个丢弃规则 | 应用第一个匹配的规则 | 状态 = 丢弃 | 按R1→R2→R3顺序检查 |
| 题记空白但无禁止备注 | 按R3处理 | 状态 = 丢弃 | 内容空缺 |
| 文本含宗教叙述但也含禁止备注 | 以禁止备注为准 | 状态 = 丢弃 | 禁止备注优先级最高 |
| 高泛化词（如空/识/戒/观心） | 必须写明限定共现条件 | 降为弱因缘 | 否则不得触发Gate |

## 7. 示例标注

### 示例 1：药师体系判定（标准流程）

**原始数据**：
"弟子某甲，为亡父造药师如来像一躯，愿亡父往生净土，安嶽工匠文氏造"

**标注过程**：
1. **前置过滤**：R1× R2× R3× → 无匹配；正向条件✓ → 允许进入分析
2. **主体判定**：药师如来（本尊名号）→ 主体 = 药师（卷四）
3. **逐卷判定**：
   - **卷四药师**：
     - 主要证据：药师如来（W=85，A层决定因），药师像（W=75，B层强因缘），往生净土（W=60，B层强因缘）
     - 次要证据：安嶽工匠文氏（W=45×0.5=22.5，C层中因缘）
     - S主要 = 85 + 75 + 60 = 220，S次要 = 22.5，S = 242.5
     - 判定：确认为该卷（S ≥ 160）
   - **卷三净土**：
     - 次要证据：往生净土（W=60×0.5=30，已在卷四计入）
     - S = 30
     - 判定：不可判定（S < 80）
4. **跨卷检查**：卷四 vs 卷三 → ⛔绝对排除 → 保留主体卷（卷四）

**标注结果**：

| 字段 | 值 | 说明 |
|------|----|------|
| 主体 | 药师琉璃光如来（卷四） | 本尊名号确定 |
| 宗派 | 药师信仰体系（卷四） | S ≥ 160 |
| 信任得分 | S = 242.5 | 主要证据充分 |
| 判定结果 | 确认为该卷 | — |
| 备注 | 主要证据充分，判定结果明确；往生净土为辅助愿望 | — |

**输出格式**：
```
判定宗派：主：药师体系·242.5（确认为该卷）

线索：
- 主要证据（原数计入）：
  - 卷四·A层决定因：药师如来（W=85，铭文中的本尊名号）
  - 卷四·B层强因缘：药师像（W=75，宗派决定因图像）
  - 卷四·B层强因缘：往生净土（W=60，铭文中的宗派判定词）
- 次要证据（减半计入）：
  - 卷八·C层中因缘：安嶽工匠文氏（W=45×0.5=22.5，匠人身份）

计算：
- S主要 = 85 + 75 + 60 = 220
- S次要 = 22.5
- S = 220 + 22.5 = 242.5

判定结果：确认为该卷（S ≥ 160）
综合得分：S = 242.5
备注：主要证据充分，判定结果明确；往生净土为辅助愿望
```

### 示例 2：观音 + 净土混合判定

**原始数据**：
"观世音菩萨，普门品，愿往生西方极乐世界"

**标注过程**：
1. **前置过滤**：通过
2. **主体判定**：观世音（本尊名号）→ 主体 = 观音（卷二）；阿弥陀往生愿文 → 卷三
3. **逐卷判定**：
   - 卷二（观音）：观世音（W=50），普门品（W=85）→ S=135
   - 卷三（净土）：往生极乐（W=70），西方（W=40）→ S=110
4. **跨卷检查**：卷三 vs 卷二 → ⚠允许并存 → 两卷并列标记

|------|-----|

## 8. 输出格式规范

### 8.1 前置过滤输出

```
状态: 进入分析 / 丢弃
说明: 简要说明判定理由
```

**批量格式**：
```
条目1: 状态: 丢弃, 说明: 显性备注型丢弃（包含"不抽取实体"）
条目2: 状态: 进入分析, 说明: 明确呈现宗教叙述
```

### 8.2 宗派判定输出

**标准输出结构**：

```
【1】主体
    主体：X（卷号）

【2】宗派（若存在）
    宗派：Y（卷号）

【3】证据权重与信任得分
    证据 | 卷 | W
    ------|-----|----
    词1 | 卷号 | W1
    词2 | 卷号 | W2
    总计：S = 总分

【4】最终判定
    根据S=[总分]，且无跨卷冲突，判定为：[主体]（主体），[宗派]（宗派）。
```

**完整输出示例**：
```
判定宗派：主：药师体系·242.5（确认为该卷）

线索：
- 主要证据（原数计入）：
  - 卷四·A层决定因：药师如来（W=85，铭文中的本尊名号）
- 次要证据（减半计入）：
  - 卷八·C层中因缘：安嶽工匠文氏（W=45×0.5=22.5）

计算：
- S主要 = 85 + 75 + 60 = 220
- S次要 = 22.5
- S = 220 + 22.5 = 242.5

判定结果：确认为该卷（S ≥ 160）
综合得分：S = 242.5
备注：主要证据充分，判定结果明确
```

**硬性规则**：
- 造像主体（观音/地藏/药师/弥勒/本师释迦等）永远不能单独作为"宗派名"出现在"判定宗派"一栏
- 主体信息应记于：线索（主体）、备注（图像体系）、或"通用大乘体系（××主体）"组合说明
- 真正的"宗派"栏只能填写：天台、净土、密教、华严、禅宗、三论、唯识、药师信仰体系、地藏信仰体系、弥勒信仰体系、民间佛教/杂修、通用大乘/宗派未定
